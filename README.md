# Python Beginner Programs

## Description
This repository contains a collection of beginner-friendly Python programs that cover a variety of basic programming concepts, including loops, conditionals, functions, user input handling, mathematical operations, and more.

## Programs Included
### 1. **Number Processing**
- Checking divisibility by 5
- Finding the maximum of two or three numbers
- Checking if a number is prime
- Calculating the cube of numbers
- Finding even and odd numbers in a list

### 2. **User Input & Interaction**
- Collecting user details (name, age, major, etc.)
- Checking if a name is a palindrome
- Asking for and validating input

### 3. **Mathematical Operations**
- Calculating the area of a triangle using Heron's formula
- Finding the sum, count, and average of numbers
- Multiplication tables
- Celsius to Fahrenheit conversion
- Meters to centimeters conversion

### 4. **Conditionals and Loops**
- Checking if a number is even or odd
- Finding valid triangle sides and angles
- Generating a right-angled triangle pattern using `*`
- Calculating the number of steps to reduce a number to 1 using division
- Determining if a student is allowed to take an exam based on attendance
- Applying discounts based on purchase amount

## How to Use
1. Clone this repository:
   ```sh
   https://github.com/hmahmoud2211/Python-Programs.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Python-Programs
   ```
3. Run any Python file using:
   ```sh
   python filename.py
   ```

- Python 3.x installed on your system
